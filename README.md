# Anti-Cocoon Engine · 意外引擎

一个"不讨好你的搜索引擎"：不给你最匹配的答案，而是打开最值得绕路的可能性。

前后端一体，**纯 Node.js，零第三方依赖**，开箱即用。融合了两个原始项目：
Serendipity-engine（LLM 意外推荐 + 反馈记忆）与 search-engine（规则检索 + 精选库），
按《Anti-Cocoon Engine 项目大纲》统一为一套东方诗云风格的可用网站，**不含任何 Python**。

## 快速开始

需要 Node.js 18+（用到内置 `fetch`）。

```bash
# Windows
start.bat

# macOS / Linux
./start.sh

# 或直接
node server.mjs
```

然后打开 http://127.0.0.1:8787 。无需安装、无需 API Key、无需 Docker。

## 一分钟看懂闭环

```
输入问题 → 生成意外检索词 → 搜索真实内容 → 解释为什么出现 → 收集反馈 → 第二次改变结果
```

演示脚本（"同题两答"）：

1. 首页输入「AI 大模型」，输入时会弹出"猜你不想搜"反补全候选。
2. 选一个意外引擎（沙之海 / 反命题 / 魔音 / 字根岔路 / 语义远眺 / A.G.E.N.T.），点「出发」。
3. 看汉字/谐音过场动画，进入结果页，看到真实检索词、瀑布流、右侧灵感卡片。
4. 点结果卡片上的「🧍 为什么会看到它」，展开解释链。
5. 点「不够偏」或「避开此类」，系统再次搜同一个词，弹出"本次使用的记忆"，结果明显变远。

## 六个意外引擎

| 模式 | 逻辑 | 依赖 |
| --- | --- | --- |
| 沙之海 | 从陌生领域池抽远方，与原问题拼接 | 规则，离线 |
| 反命题 | 分词取反 / 目的取反，翻到问题背面 | 规则，离线 |
| 魔音 | 谐音、近音、形近，把严肃词转成荒诞意象 | 规则，离线 |
| 字根岔路 | 拆解汉字部首，从字源意象重新联想 | 规则，离线 |
| 语义远眺 | 用偏离度切分领域池的"远近带"，模拟语义距离 | 规则，离线 |
| A.G.E.N.T. | 大模型结合记忆生成意外检索词 | 需连接模型；未连接时自动降级到规则引擎 |

偏离度 = 0 时进入直答模式，直接检索原词，不绕路。

## 可选增强

两项都是可选的，不配置也完全可用：

- **真实全网搜索（SearXNG）**：设置环境变量 `SEARXNG_URL` 后，搜索源自动从"精选库"切到 SearXNG 实时结果。参见 `.env.example`。
- **A.G.E.N.T. 引擎 + 自然语言反馈**：页面右上角「连接模型」，填任意 OpenAI 兼容接口（DeepSeek / Kimi / 通义 / 智谱 / 硅基流动 / 本地 Ollama）。API Key 仅存内存，不写磁盘、不上传。

## 项目结构

```
anti-cocoon-engine/
├─ server.mjs           # 前后端一体服务（HTTP + API + 静态文件），零依赖
├─ lib/
│  ├─ lexicon.mjs       # 词库：陌生领域池 / 反义 / 谐音 / 部首 / 诗句模板
│  ├─ engines.mjs       # 六个意外引擎（离线规则版）
│  ├─ search.mjs        # 搜索适配器：SearXNG 或精选库
│  ├─ curated.mjs       # 离线精选结果库（真实链接）
│  ├─ cards.mjs         # 右侧卡片生成器（双盲诗/灵感卡/答案之书/别人也在逃离/今日误读）
│  ├─ memory.mjs        # 反馈记忆层（memory.json + feedback.jsonl）
│  └─ llm.mjs           # 可选 LLM 层（A.G.E.N.T. + 反馈解析）
├─ public/
│  ├─ index.html        # 首页（搜索框/引擎菜单/反补全/偏离度）
│  ├─ results.html      # 结果页（过场/瀑布流/解释链/卡片/反馈）
│  ├─ app.css           # 东方诗云 · 纯白衬线 · 陈列感
│  ├─ common.js         # 前端共用工具
│  ├─ home.js           # 首页逻辑
│  └─ results.js        # 结果页逻辑
├─ data/                # 运行时生成：memory.json / feedback.jsonl
├─ smoke-test.mjs       # 冒烟测试（需先启动服务）
├─ start.bat / start.sh # 一键启动
└─ .env.example         # 可选环境变量说明
```

## 测试

先启动服务，再另开一个终端：

```bash
node smoke-test.mjs
```

覆盖：六引擎生成、反补全、谐音替换、五张卡片、反馈动作、同题两答记忆、自然语言规则解析、直答模式。

```
诗性，但能交互。
随机，但能记忆。
```
